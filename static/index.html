공개 시각 기준 지연
피드가 명시한 정확한 공개 시각부터 수집기가 발견한 시각까지입니다. 발행 시스템과 캐시의 지연도 포함합니다.
피드 수정 시각 기준 지연
GitHub 릴리스 Atom은 published 없이 updated만 제공할 수 있습니다. 이 경우 최초 공개 지연으로 바꾸어 부르지 않습니다.
관측 구간
직전 정상 확인부터 발견까지의 간격입니다. 변경 발생 시각이 아니며, 원문 공개 지연의 상한을 보장하지 않습니다.
알림 접수
macOS가 알림 요청을 접수한 시각입니다. 배너 표시·휴대폰 도착·사용자 열람 시각과는 다릅니다. 집중 모드 등으로 표시가 늦어질 수 있습니다.
통계에 포함되지 않는 항목
최초 기준선의 기존 글, 자체 시험, 날짜만 있는 글, 미래 시각, 기준선보다 오래된 글, 수정 시각이 없는 편집, X 수동 기록입니다.
검색·커뮤니티·논문 배치·사이트맵·모델 등록 시각
Google News의 표기 시각, 커뮤니티 게시 시각, arXiv 일괄 공지, 사이트맵 수정 및 모델 저장소 생성 시각은 원문 최초 공개 시각으로 보지 않으며 실전 공개 지연 통계에서 제외합니다.

국내 최초 여부는 측정하지 않습니다. 실제 신규 소식이 발생하기 전에는 실전 지연 통계가 비어 있는 것이 정상입니다.

공식 X 알림
